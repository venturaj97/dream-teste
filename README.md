# dream-teste

Projeto desenvolvido como parte de um teste técnico utilizando Terraform para provisionamento de infraestrutura.

## Tecnologias utilizadas

- Terraform
- Shell Script
- AWS

## Objetivo

O projeto teve como objetivo automatizar a criação e configuração de recursos de infraestrutura através de Infrastructure as Code (IaC).

## Observação

O projeto não foi finalizado, mas permanece disponível como registro do desenvolvimento realizado durante o processo seletivo.
